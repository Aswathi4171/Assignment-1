# 📊 Excel Data Analysis Assignment

## 📌 About the Project

This project is an **Excel data analysis assignment** focused on working with product sales data and applying different Excel functions to extract, categorize, and analyze information.

The dataset contains details such as **Product ID, Product Name, Brand, Price, Quantity, Category, Country, and Month**.

## 📁 Dataset

The Excel workbook contains the following columns:

* Product ID
* Product Name
* Brand Name
* Price ($)
* Quantity
* Category
* Price Range
* Day
* Country
* Month

## 🛠️ Excel Functions Used

The assignment demonstrates the use of several Excel functions:

* **IF** – To classify products based on their price.
* **LEFT** – To extract the day from the Product ID.
* **RIGHT** – To extract the country code from the Product ID.
* **MID** – To extract the month from the Product ID.
* **COUNTIF** – To count products based on specific conditions.

## 🎯 Objectives

The main objectives of this assignment are:

1. Practice basic Excel formulas and functions.
2. Extract useful information from Product IDs.
3. Categorize products based on their price.
4. Perform conditional counting.
5. Improve data analysis and Excel skills.
